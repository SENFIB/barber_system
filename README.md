# ESMAIRO (اِسمایرو)

سامانه‌ی نوبت‌دهی آنلاین برای انواع کسب‌وکار (آرایشگاه، زیبایی، سلامت و تندرستی، خودرو، خدمات حرفه‌ای، آموزش، حیوانات خانگی).
یک اپ واحد برای **اندروید** و **ویندوز** (iOS بعداً) با دو بخش: **مشتری** و **کسب‌وکار**.

- نام نمایشی: ESMAIRO (فارسی: اِسمایرو، عربی: إسمايرو)
- شناسه‌ی بسته: `com.barberapp` (ثابت، تغییر نکند)
- زبان‌ها: فارسی، English، العربية
- تقویم‌ها: شمسی (فارسی)، هجری قمری (عربی)، میلادی (انگلیسی)
- توسعه‌دهنده: اسماعیل

---

## بخش مشتری

- انتخاب دسته‌ی کسب‌وکار قبل از جست‌وجو
- جست‌وجو بر اساس نام، شهر، نوع، جنسیت (فقط آرایشگاهی)، بیشترین خدمات
- فهرست «پرجست‌وجو» و «محبوب»
- نمایش عکس، آدرس، تلفن، ساعت‌های خالی و قیمت خدمات
- رزرو با انتخاب خدمت (تا ۳ خدمت هم‌زمان) و نفر پرسنل
- شروع نوبت (ثبت حضور)، لغو (طبق قانون هر کسب‌وکار)، امتیازدهی ناشناس
- یادآوری ۲ ساعت و ۱۰ دقیقه قبل از نوبت
- دکمه‌ی فروشگاه/سایت کسب‌وکار و پوسته‌ی اختصاصی (پلن ویژه)
- حساب مشتری بدون رمز عبور (بر پایه‌ی شناسه‌ی دستگاه)
- نام واقعی هنگام رزرو الزامی است

## بخش کسب‌وکار

- ورود، ثبت‌نام مدیر جدید (با کد لایسنس) یا پرسنل (با کد دعوت)
- ترتیب ثبت‌نام: انتخاب پلن ← انتخاب دسته‌ی کسب‌وکار ← اطلاعات مدیر
- متن‌ها، آیکن‌ها و خدمات پیشنهادی بر اساس نوع کسب‌وکار
- مدیریت نوبت‌ها (جاری، انجام‌شده، نیامده، لغوشده)، نمایش جدولی در ویندوز
- «کار تمام شد» و «نیامده» از ابتدای نوبت فعال و ۱۵ دقیقه پس از پایان غیرفعال می‌شوند
- **پنل درآمد:** مدیر درآمد کل، تعداد مشتری و سهم هر نفر پرسنل را می‌بیند؛ هر نفر فقط مشتریان و مبالغ خودش را
- مدیریت پرسنل و نقش‌ها، ساعت کاری و شیفت‌ها، مرخصی‌ها و تعطیلی‌ها
- مدیریت خدمات (قیمت، مدت، ارز انتخابی)
- قوانین رزرو: بازه‌ی رزرو، روز تعطیل هفتگی، قانون لغو، گام زمانی (پیش‌فرض ۵ دقیقه)
- ثبت دستی نوبت‌های تلفنی
- تبلیغات (کد تبلیغ، انتخاب دسته‌های نمایش، گزینه‌ی بدون تبلیغ)
- فروشگاه/سایت (پرو و ویژه)
- پیام اختصاصی کسب‌وکار در بازه‌های مشخص (ویژه)

## پلن‌ها (اشتراک ۳۰ روزه)

| پلن | پرسنل | شیفت | پاکسازی سوابق | ویژگی‌ها |
|---|---|---|---|---|
| پایه | ۱ | ۲ | ۷ روز | رایگان، فضای مشترک، تبلیغ اختیاری (پولی) |
| پرو | ۵ | ۳ | ۱۴ روز | فروشگاه تا ۳ محصول (فقط نام) |
| ویژه | تا ۳۰ | ۵ | ۳۰ روز | فضای اختصاصی، عکس کسب‌وکار، پوسته‌ی اختصاصی، پیام اختصاصی، فروشگاه تا ۵ محصول با عکس، تبلیغ رایگان |
| شخصی | نامحدود | ۵ | – | خرید یکباره، راه‌اندازی توسط خود کسب‌وکار |

- اشتراک با کد لایسنس فعال می‌شود؛ هر لایسنس فقط برای یک کسب‌وکار.
- هشدار انقضا ۳ روز و ۱ روز قبل؛ پس از انقضا پنل قفل می‌شود.
- تغییر پلن از داخل پنل (کد لایسنس دارم / تمدید ← تغییر پلن).
- پرسنل به اشتراک مدیر وابسته‌اند.

## نقش‌ها

- **مدیر:** دسترسی کامل
- **پرسنل:** با کد دعوت یک‌بارمصرف (۷ روز اعتبار، قفل روی یک دستگاه)؛ فقط نوبت‌ها، ساعت‌ها و مرخصی خودش را می‌بیند
- **مشتری:** بدون ثبت‌نام

## معماری

- **اپ:** Flutter (اندروید و ویندوز)
- **سرور:** Google Apps Script؛ بدون سرور پولی. در متن‌ها و توضیحات فقط «سرور» گفته می‌شود.
- داده‌ها بر اساس پلن جدا نگهداری می‌شوند: پایه روی سرور اصلی، پرو روی سرور دوم (مسیریابی خودکار)، ویژه روی سرور اختصاصی هر کسب‌وکار، شخصی روی سرور خود مالک.
- عکس‌ها در فضای ابری ذخیره می‌شوند.
- پاکسازی شبانه‌ی سوابق قدیمی طبق پلن.

## ساختار مخزن

- `.gitignore`
- `README.md`
- `.github/workflows/build.yml`: ساخت خودکار اندروید و ویندوز
- `packages/barber_core/`: هسته‌ی مشترک (کلاینت API و مدل‌ها)
- `barber_app/`: اپ اصلی
  - `pubspec.yaml`
  - `assets/logo.png`: لوگوی ESMAIRO (مربع، حدود ۱۰۲۴ پیکسل)
  - `assets/fonts/`: فونت Vazirmatn (در زمان بیلد دانلود می‌شود)
  - `lib/main.dart`
  - `lib/app/`: تنظیمات، رشته‌ها (۳ زبان)، تقویم‌ها، ارز، قالب و ویجت‌های مشترک، متن‌های حقوقی
  - `lib/features/onboarding/`: زبان و انتخاب نقش
  - `lib/features/legal/`: حریم خصوصی و شرایط
  - `lib/features/settings/`: تنظیمات و ظاهر
  - `lib/features/customer/`: بخش مشتری
  - `lib/features/manager/`: بخش کسب‌وکار
- `tools/make_icon.py`: ساخت آیکن اپ از `logo.png`
- `keystore/`: به‌صورت خودکار توسط Actions ساخته می‌شود

پوشه‌های `android/` و `windows/` در مخزن نیستند و هنگام بیلد با `flutter create` ساخته می‌شوند.

## ساخت (Build)

فقط با GitHub Actions؛ نیازی به نصب چیزی روی رایانه نیست.

1. فایل‌ها را در یک کامیت روی شاخه‌ی `main` بفرستید (یا از Actions دکمه‌ی Run workflow را بزنید).
2. در تب **Actions** جدیدترین ران را باز کنید.
3. پس از سبز شدن، از بخش Artifacts دانلود کنید:
   - `ESMAIRO-android` (فایل `ESMAIRO.apk`)
   - `ESMAIRO-windows` (فایل `ESMAIRO.exe`)

مشخصات بیلد:
- اندروید: Ubuntu، Java 17، Flutter 3.27.4، با امضای keystore و `--obfuscate`
- ویندوز: `windows-2022`، Flutter 3.27.4
- نسخه: `1.0.<PATCH>` با شماره‌ی بیلد برابر شماره‌ی ران

اگر بیلد قرمز شد، متن خطا را از همان ران جدید کپی کنید.
